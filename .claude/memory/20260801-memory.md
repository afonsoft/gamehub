# 2026-08-01 — long-term memory

## Decisions
- **Migrar o harness para a estrutura nativa do Claude Code** — manter apenas `CLAUDE.md` + `.claude/` e `.devin/config.json` mínimo; eliminar estruturas legadas (`AGENTS.md`, `.agents/`, `.devin/hooks/`, `.claude/CONTEXT.md`, `.claude/MEMORY.md`, `.claude/README.md`, `.claude/RULES.md`, `.claude/TOOLS.md`, `.claude/WORKFLOWS.md`, `Api/.windsurf/`). Alternativa descartada: manter `AGENTS.md` como source of truth (o playbook proíbe estruturas paralelas).
- **Mover `.agents/skills/*` para `.claude/skills/*`** — preservar os 35 skills e histórico via `git mv`.
- **Remover hooks locais de proteção de branch** — proteção de `main`/`master`/`develop` e `.github/workflows` é server-side + `global-rules.md`; hooks locais são frágeis.
- **Simplificar `.devin/config.json`** — apenas `read_config_from.claude: true`; source of truth permanece `.claude/settings.json`.

## Lessons learned
- **Arquivos na raiz de `.claude/` (CONTEXT, MEMORY, README, RULES, TOOLS, WORKFLOWS) não fazem parte da estrutura nativa do Claude Code** — devem migrar para `CLAUDE.md`, `.claude/rules/global-rules.md`, `.claude/memory/` ou `.claude/knowledge/`.
- **`.devin/hooks/` duplicava `.claude/hooks/`** — Devin CLI lê `.claude/settings.json` quando `read_config_from.claude: true`, tornando o diretório redundante.

## Technical debt
- **Cobertura de testes baixa (~10%)** — impacto: risco de regressões. Prioridade: alta. Herdado de `.claude/MEMORY.md` e `AGENTS.md`.
- **`GameHub.Web.Tests` com testes skipped** — cobertura web não confiável. Prioridade: média.
- **`InMemoryGameCatalogCache` temporário** — impacto em performance em produção. Prioridade: média.

## Discoveries
- **`.agents/skills/` continha 35 skills** em formato SKILL.md válido, todos migrados para `.claude/skills/` sem colisões (fonte: `find .agents/skills -name SKILL.md`).
- **`Api/.windsurf/skills/aspnet-boilerplate-api-development.md`** existia como harness legado do Windsurf; convertido para `.claude/knowledge/aspnet-boilerplate-api-development.md` e `Api/.windsurf/` removido (fonte: `Api/.windsurf/skills/aspnet-boilerplate-api-development.md`).
- **`.claude/settings.json` negava `Read(.github/workflows/**)` e `Bash(git push * main*)`** — excessivamente restritivo para leitura de workflows; ajustado para `deny` de arquivos sensíveis apenas.
