## 2026-08-13 — Ajustes de layout do portal do desenvolvedor (/developer)

### Contexto
Usuário reportou que as telas `/developer`, `/developer/earnings`, `/developer/team` e `/developer/profile` estavam com layout ruim, difícil de ler e quebrado, e pediu um link para o `gamehub-admin`.

### Causa raiz
As telas filhas do `DeveloperShellComponent` ainda usavam o wrapper `.dev-page`, que define uma grid com coluna lateral de 248px. Como o shell já possui sua própria sidebar, isso criava uma coluna vazia dentro do conteúdo, quebrando o layout.

### Ações
- Removido `.dev-page` de `earnings`, `games`, `builds` e `metrics`.
- Reescritos `dashboard.component.css` e `earnings.component.css` com design tokens claros do `:root`, cards, painéis e tabelas roláveis.
- Atualizados `team.component.css` e `profile.component.css` para reaproveitar os estilos do `game-create` e adicionar estilos específicos de tenants e listas.
- Adicionado `adminUrl` em `environment.ts` e `environment.prod.ts`.
- Exposto `adminUrl` no `developer-shell` e `dashboard`.
- Incluído link externo "GameHub Admin" na sidebar do `developer-shell` e no cabeçalho do dashboard.
- Ajustado budget de `anyComponentStyle` no `angular.json` para acomodar os novos estilos.

### Validação
- `npm run build` concluído sem erros.
- `npx ng test --watch=false --browsers=ChromeHeadless` passou 8/8.

### Decisões
- Não abrir PR automaticamente conforme `CLAUDE.md`; informar branch `devin/ajuste-layout-developer` ao usuário.
