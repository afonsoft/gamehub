GameHub Docs

Admin, SDK and API guides.

Guia do Admin

O painel GameHub centraliza moderação, builds, empresas/tenants, reports e métricas.

  • Dashboard: plays diários, jogos em alta e uploads recentes.
  • Games: lista de jogos publicados e pendentes com ações de suspensão.
  • Uploads / Inspector: valide builds, visualize arquivos e execute checklists de qualidade.
  • Moderation: aprove, rejeite ou peça alterações em jogos enviados para revisão.
  • Companies: gerencie tenants/empresas e associe funcionários.
  • Reports: revise denúncias de jogadores e atualize status.
  • API Sandbox: teste endpoints com Swagger quando disponível.

Admin Guide

The GameHub panel centralizes moderation, builds, companies/tenants, reports and metrics.

  • Dashboard: daily plays, trending games and recent uploads.
  • Games: list of published and pending games with suspend actions.
  • Uploads / Inspector: validate builds, browse files and run quality checklists.
  • Moderation: approve, reject or request changes for submitted games.
  • Companies: manage tenants/companies and associate employees.
  • Reports: review player reports and update statuses.
  • API Sandbox: test endpoints with Swagger when enabled.
