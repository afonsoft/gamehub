Guia do Painel GameHub

O painel GameHub centraliza a administração de jogos, empresas, builds, moderação e relatórios.

  • Dashboard: visão geral por perfil (admin, moderador ou desenvolvedor) e tenant atual.
  • Games: listagem, filtros por status e ações do ciclo de vida (iniciar revisão, aprovar, solicitar alterações, publicar, suspender).
  • Uploads: builds enviados, validação, status e arquivos.
  • Inspector: sessões de inspeção para validação de SDK e integração.
  • Moderation: fila de revisões com filtros por status (Pending, InProgress, Completed).
  • Reports: denúncias de usuários com atualização de status.
  • Companies: cadastro de empresas/tenants, convites e gerenciamento de funcionários.
  • Test Session / API Sandbox: teste de jogos antes da publicação e exploração da API via Swagger.
  • Docs / Help: documentação e este guia.

A documentação completa está em docs/gamehub-admin-features.md e docs/gamehub-features.md.

GameHub Admin Guide

The GameHub admin panel centralizes game, company, build, moderation and report management.

  • Dashboard: role-aware overview (admin, moderator or developer) and current tenant.
  • Games: listing, status filters and lifecycle actions (start review, approve, request changes, publish, suspend).
  • Uploads: uploaded builds, validation, status and files.
  • Inspector: inspection sessions for SDK and integration validation.
  • Moderation: review queue filtered by status (Pending, InProgress, Completed).
  • Reports: user reports with status updates.
  • Companies: company/tenant registration, invitations and employee management.
  • Test Session / API Sandbox: test games before publishing and explore the API via Swagger.
  • Docs / Help: documentation and this guide.

Full documentation is in docs/gamehub-admin-features.md and docs/gamehub-features.md.
