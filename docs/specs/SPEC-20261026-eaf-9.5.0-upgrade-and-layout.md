## 1. User Story
- **As a** Maintainer / Developer of GameHub,
- **I want** to upgrade the platform to the newly released EAF version 9.5.0, modernize layout components in both the public Hub and the Admin portal, and expand our test coverage,
- **So that** we benefit from the latest framework bug fixes, security enhancements, polished UI/UX layouts, and robust test guarantees across all modules.

## 2. Scope
### In Scope
- Updating EAF NuGet package references from `9.4.6` to `9.5.0` across all `.csproj` files and `common.props`.
- Improving UI/UX layout components in Angular Hub (public portal) and Angular Admin (`GameHub.UI`).
- Enhancing unit and integration test suites (`GameHub.Tests`, `GameHub.Web.Tests`, and Angular tests) targeting new features and regression prevention.
- Validating solution build, package resolution, and test suite execution.

### Out of Scope
- Rewriting core domain architecture or changing database providers.
- Modifying production deployment scripts or CI/CD runner environments outside GitHub Actions.

## 3. Technical Context
- **Files to modify**:
  - `Api/common.props` (updating `<Version>` / `<TemplateVersion>` to `9.5.0`)
  - `Api/src/**/*.csproj` (updating `Eaf.Middleware.*` package versions to `9.5.0`)
  - Angular styling and component files in `angular/` and `angular-admin/GameHub.UI/`
  - Test projects in `Api/test/GameHub.Tests/` and `Api/test/GameHub.Web.Tests/`
- **Tooling**: .NET 10 SDK, NuGet, Angular CLI, xUnit, git.

## 4. Requirements
- **RF-001 (EAF Version Upgrade)**: O backend .NET deve ter suas referências aos pacotes NuGet `Eaf.Middleware.*` atualizadas para a versão `9.5.0` (em `common.props` e arquivos `.csproj`).
- **RF-002 (Layout Improvements)**: Aprimoramento visual e de responsividade no Portal Público (`angular/`) e Painel Administrativo (`angular-admin/GameHub.UI/`), refinando barras de navegação, modais, espaçamentos e consistência de design tokens.
- **RF-003 (Test Suite Enhancement)**: Ampliação e refinamento da suíte de testes xUnit e testes de integração, assegurando cobertura em novas funcionalidades e correção de eventuais regressões da atualização.
- **Business Rules / Invariants**:
  - Manter compatibilidade com .NET 10 e C# 14.
  - Preservar os padrões de Clean Architecture, DDD e SOLID nas camadas de Core, Application e Infrastructure.
  - Zero tolerância para falhas de build ou testes quebrados após a migração.

## 5. API Contract
*Nenhum contrato de API público alterado (atualização interna de framework e layout).*

## 6. Acceptance Criteria
### BDD Scenarios
- **Given** os arquivos de projeto .NET referenciam EAF 9.4.6,
- **When** o framework é atualizado para EAF 9.5.0 em `common.props` e `.csproj`,
- **Then** o build da solution compila sem erros ou avisos críticos de dependência.

- **Given** o layout atualizado no Hub e no Admin,
- **When** os aplicativos Angular são compilados (`ng build`),
- **Then** os pacotes compilam com sucesso e a interface exibe os refinamentos visuais propostos.

### Edge Cases Table
| Scenario | Input | Expected Behavior |
|---|---|---|
| Conflito de versão de pacotes NuGet | Versão 9.5.0 de `Eaf.Middleware` com dependências transitivas | Restauração limpa `--no-cache --force` resolve dependências corretamente. |
| Incompatibilidade de API EAF | Mudança de assinatura em serviços base do EAF 9.5.0 | Ajustes cirúrgicos no código de aplicação para adaptar-se à nova versão. |
