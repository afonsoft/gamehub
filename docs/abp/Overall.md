### Introduction [Anchor](https://aspnetboilerplate.com/Pages/Documents/Zero/Overall\#introduction)

The ASP.NET Boilerplate framework is designed to be independent of any
database schema and to be as generic as possible. Therefore, it leaves
some concepts **abstract** and **optional**, like audit logging, session
management and authorization, which require some sort of **data store**.

**Module Zero** implements all the fundamental concepts of the ASP.NET
Boilerplate framework such as [tenant management](https://aspnetboilerplate.com/Pages/Documents/Zero/Tenant-Management)
( **multi-tenancy**), [role management](https://aspnetboilerplate.com/Pages/Documents/Zero/Role-Management), [user management](https://aspnetboilerplate.com/Pages/Documents/Zero/User-Management),
[session](https://aspnetboilerplate.com/Pages/Documents/Abp-Session), [authorization](https://aspnetboilerplate.com/Pages/Documents/Authorization) ( [permission management](https://aspnetboilerplate.com/Pages/Documents/Zero/Permission-Management)), [setting management](https://aspnetboilerplate.com/Pages/Documents/Setting-Management),
[language management](https://aspnetboilerplate.com/Pages/Documents/Zero/Language-Management), [audit logging](https://aspnetboilerplate.com/Pages/Documents/Audit-Logging) and more.

### Microsoft ASP.NET Identity [Anchor](https://aspnetboilerplate.com/Pages/Documents/Zero/Overall\#microsoft-asp-net-identity)

This module has two versions:

- The Abp.Zero.\* packages are built on Microsoft ASP.NET Identity and
Entity Framework 6.x.
- The Abp.ZeroCore.\* packages are built on Microsoft ASP.NET Core
Identity and Entity Framework Core.

See [all packages](https://aspnetboilerplate.com/Pages/Documents/Nuget-Packages).

### Source code [Anchor](https://aspnetboilerplate.com/Pages/Documents/Zero/Overall\#source-code)

The source code of this module is also maintained in [the main GitHub repository](https://github.com/aspnetboilerplate/aspnetboilerplate/tree/dev/src) (Abp.Zero.\* and Abp.ZeroCore.\* projects).
