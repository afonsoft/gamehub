# GameHub — Funcionalidades / Features

## Português (pt-BR)

O **GameHub** é um portal de jogos HTML5/WebGL com catálogo público, execução em iframe via SDK bridge, perfil de jogador, leaderboards e chat.

### Jogador
- **Catálogo**: busca por texto, filtro por categoria, tag, dispositivo e orientação.
- **Detalhe do jogo**: informações, avaliação, jogos relacionados e CTA "Jogar".
- **Execução**: iframe sandboxed, overlay "Start Game", SDK bridge (loading, gameplayStart/Stop, commercialBreak, rewardedBreak).
- **Perfil**: favoritos, jogos recentes, seleção de tenant/empresa.
- **Leaderboard**: ranking por jogo e modo.

### Desenvolvedor / Empresa
- **Portal do desenvolvedor**: dashboard, cadastro/edição de jogos, upload de builds, métricas e analytics.
- **Submissão e moderação**: enviar jogo para revisão, acompanhar status, receber feedback.
- **Empresa**: tenant próprio com funcionários e permissões.

### Integração
- **SDK JavaScript** para jogos HTML5.
- **API REST** documentada via Swagger/OpenAPI.

## English (en-US)

**GameHub** is an HTML5/WebGL game portal with a public catalog, iframe execution via SDK bridge, player profile, leaderboards and chat.

### Player
- **Catalog**: text search, filter by category, tag, device and orientation.
- **Game detail**: info, rating, related games and "Play" CTA.
- **Execution**: sandboxed iframe, "Start Game" overlay, SDK bridge (loading, gameplayStart/Stop, commercialBreak, rewardedBreak).
- **Profile**: favorites, recent games, tenant/company selection.
- **Leaderboard**: per-game and per-mode ranking.

### Developer / Company
- **Developer portal**: dashboard, game create/edit, build upload, metrics and analytics.
- **Submission & moderation**: submit games for review, track status and feedback.
- **Company**: dedicated tenant with employees and permissions.

### Integration
- **JavaScript SDK** for HTML5 games.
- **REST API** documented via Swagger/OpenAPI.
