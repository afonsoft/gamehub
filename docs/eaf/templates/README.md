# Templates do EAF

Esta seção detalha os templates fornecidos pelo EAF para iniciar novos projetos.

## Templates Disponíveis

* [Angular UI Template](./angular-ui-template.md) - Template de interface de usuário usando Angular 18
* [ASP.NET Core API Template](./aspnet-core-api-template.md) - Template de API REST usando ASP.NET Core
* [Worker Template](./worker-template.md) - Template para serviços de background

## Visão Geral

O EAF fornece templates para facilitar a criação de novos projetos baseados no framework. Cada template inclui:

- Configuração pré-definida dos módulos EAF
- Estrutura de projeto otimizada
- Exemplos de código e componentes
- Integração com as melhores práticas do EAF
