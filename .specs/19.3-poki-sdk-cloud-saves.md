# 19.3 - SDK Poki, Cloud Saves e Incognito (Fase 3)

> **Status:** Planejado  
> **Base:** `.specs/19-poki-backlog.md`

---

## 1. Objetivo

Alinhar o `GameplayBridge` e o SDK do jogo com a documentação da Poki, tornando-o seguro em modo anônimo e capaz de sincronizar saves.

---

## 2. Escopo

### 2.1 SDK Promise
- `GameHubSDK.init()` retorna Promise.
- Resolver após handshake com `gameLoadingFinished`.

### 2.2 Regras de Sequência (complemento)
- `gameplayStart()` no primeiro input do jogador (não apenas após `startSession`).
- `gameplayStop()` em pausa, game over, menu, cutscene.
- Não permitir dois eventos iguais seguidos.

### 2.3 Incognito / Storage
- Todos os acessos a `localStorage` e `IndexedDB` em try/catch.
- Prefixo `gamehub_ignore_` para chaves que não devem ser sincronizadas.

### 2.4 Cloud Saves
- Sincronizar `localStorage` + `IndexedDB` para usuários logados.
- Limite de 1 MB após gzip.
- Fallback para local quando offline ou não logado.

### 2.5 Login do Jogador no SDK
- `GameHubSDK.login()` abre painel OAuth.
- `GameHubSDK.getUser()` retorna `{ username, avatarUrl }`.
- `GameHubSDK.getToken()` retorna JWT de curta duração.

---

## 3. Critérios de Aceite

- Bridge state machine coberto por testes unitários.
- Nenhum erro de storage em modo privado.
- Backend de cloud save com endpoints `GET/POST /api/services/app/CloudSave`.
- i18n e docs atualizadas.
