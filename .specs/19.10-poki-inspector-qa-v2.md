# 19.10 - Inspector de QA v2 (Scaling, Eventos e Warnings)

> **Status:** Planejado  
> **Base:** `.specs/18-poki-referencia.md` seção 5.5; `.specs/19.5-poki-inspector-qualidade.md`  
> **Objetivo:** Evoluir o GameHub Inspector com testes de scaling, log de eventos do SDK e detalhamento de warnings.

---

## 1. Contexto

O Inspector atual (`/app/main/gamehub/inspector`) lista relatórios de validação de builds. A próxima iteração deve permitir que moderadores e desenvolvedores carreguem uma build, executem em iframe e vejam comportamento do SDK em tempo real.

---

## 2. Escopo

### 2.1 Entidades
- `InspectorSession`: `Id`, `GameId`, `BuildId`, `StartedAt`, `DevicePreset`, `Resolution`, `Status`.
- `InspectorSdkEvent`: `Id`, `SessionId`, `EventType`, `Payload`, `Timestamp`.
- `InspectorWarning`: `Id`, `SessionId`, `Category`, `Message`, `Severity`.

### 2.2 Backend
- `IInspectorAppService`:
  - `StartSessionAsync(StartInspectorSessionInput)`
  - `LogSdkEventAsync(LogSdkEventInput)`
  - `AddWarningAsync(AddInspectorWarningInput)`
  - `GetSessionAsync(Guid sessionId)`
  - `GetSessionsAsync(GetInspectorSessionsInput)`
- Reaproveitar `BuildValidationAppService.GetReportAsync` para preencher warnings iniciais.

### 2.3 Frontend (admin)
- Nova página `/app/main/gamehub/inspector/session/:id`.
- Seletor de dispositivo (`Desktop`, `Mobile`, `Tablet`) e resolução (640x360, 836x470, 1031x580, 16:9, etc).
- Iframe sandbox rodando o build selecionado.
- Painel lateral com:
  - Log de eventos do SDK (`gameplayStart`, `commercialBreak`, etc).
  - Checklist de QA por módulos.
  - Lista de warnings categorizados (`ExternalRequest`, `ImageOptimization`, `SdkMisuse`, `LargeFile`).

### 2.4 Integração com SDK
- `GameplayBridgeService` no jogo pode enviar eventos para `InspectorSdkEvent` quando em modo inspector (`?inspector=true` na query string do iframe).

---

## 3. Critérios de Aceite

- Migração EF Core para `InspectorSession`, `InspectorSdkEvent` e `InspectorWarning`.
- Testes de integração para início de sessão e logging.
- Página admin permite selecionar resolução e ver eventos.
- Warnings preenchidos automaticamente a partir do relatório de validação.
- Build e testes passam.
